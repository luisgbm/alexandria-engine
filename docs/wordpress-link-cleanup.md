# Removing the seven broken links in WordPress

These links are embedded in the bodies of eight old posts, not generated by the
new engine or category/navigation settings. The retained WordPress HTML contains
the links directly. The original database has no matching missing page/translation
or old-slug record. The old content may once have existed outside this backup;
its absence does not establish when or why it disappeared.

The owner approved removing obsolete links on 2026-10-23. The Alexandria candidate
has the changes below; no access to the original server/site was performed.

## WordPress editing steps

1. Sign in to your normal WordPress dashboard yourself. Open **Posts → All Posts**
   (**Posts → Todos os posts**) and search for a title below.
2. Open **Edit / Editar**. If easier, while signed in use your normal site's
   `/wp-admin/post.php?post=ID&action=edit`, replacing `ID` with the number below.
   These IDs come from the preserved database; confirm the title before editing.
3. In the Classic Editor use **Visual** for normal text or **Text / Texto** to
   find the HTML link. In the block editor use the relevant paragraph block;
   HTML mode is optional. You do not need to install a plugin or edit the database.
4. Make the specified change, preview it, then click **Update / Atualizar** (or
   **Save / Salvar**, depending on the editor). Preserve the post title, permalink
   and original publication date.
5. Open the article and check its corrected paragraph. If cached content persists,
   refresh or clear the site's existing cache through its usual controls.

Official reference: [WordPress Classic Editor documentation](https://wordpress.org/documentation/article/write-posts-classic-editor/).
