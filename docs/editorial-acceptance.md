# Desktop and mobile acceptance

Use disposable content on an isolated instance. On both device classes:

1. Sign in with the device's registered passkey.
2. Create/edit an article, insert a More marker and save a private draft.
3. Upload a non-sensitive supported image, set alt text/caption and insert its HTML.
4. Inspect preview, including responsive image sizing and sidebar placement.
5. Publish, wait for the modal to complete, then verify the public text and image.
6. Roll back and confirm the previous public bytes return while drafts survive.
7. Exercise revision restore, category filters, trash and protected deletion.
8. Remove the fixtures using normal safeguards and verify the site's expected URLs.

Check that feedback appears near the relevant controls, buttons cannot submit
conflicting operations, and success messages expire appropriately. Never delete
the last passkey or run a credential-reset drill against active users.
